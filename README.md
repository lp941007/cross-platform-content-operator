# Cross-Platform Content Operator

An evidence-based Codex skill for creating truthful, executable, platform-specific content strategies, scripts, BGM plans, production workflows, and measurable growth tests.

## Install

Ask your agent to run:

```bash
npx -y skills add lp941007/cross-platform-content-operator@cross-platform-content-operator --agent codex
```

The skill will be available to Codex after installation; start a new session if it does not appear immediately.
